How does a network know what to adjust?

Two things, side by side: what those architecture numbers actually mean, and — the real answer to "how does it know" — backpropagation, which is the chain rule run backward through every layer.

Architecture terms — drag to see how they scale

hidden_dim
The width of the vector that represents each token as it flows through the network. Everything — embeddings, attention, MLP — operates on vectors this wide.
layers
How many times the vector gets passed through an attention+MLP block in sequence. Each pass refines the representation further.
attention heads
Each attention layer splits its work into this many parallel, smaller attention computations, each with dimension hidden_dim ÷ heads — one might track grammar, another long-range references, etc.
vocab_size
How many distinct tokens the tokenizer can produce — sets the size of the embedding table and the final logit layer.

The chain rule, in one sentence

The loss function only ever looks at the final output. To find out how much an early layer's weights are to blame, backprop multiplies the error at the output by every derivative on the path back to that layer — layer 2's gradient first, then layer 1's gradient is computed from layer 2's, one step at a time, all the way to the input. No layer is ever graded directly against the training label except the last one; every earlier layer only ever learns from the layer just downstream of it.
